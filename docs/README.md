## 기능 목록 작성


### 입력
- [ ] 사용자는 출발역을 입력할 수 있다.

- [ ] 사용자는 도착역을 입력할 수 있다.

- [ ] 사용자는 안내 및 목록에 따라, 원하는 기능을 선택하여 입력할 수 있다.


### 출력
- [ ] 기대하는 출력 결과는 `[INFO]`를 붙여서 출력한다.

- [ ] 에러 발생 시 `[ERROR]`를 붙여서 출력한다.


- 1. 메인 화면
  - [ ] "`## 메인 화면`" 메시지를 출력한다.

  - [ ] 입력 받을 `기능 목록`을 출력한다.
    ```
    ex:
    1. 경로 조회
    Q. 종료
    ```

  - [ ] 기능 목록 입력 안내 메시지를 출력한다.
  
     -> "`## 원하는 기능을 선택하세요.`"


- 2. 경로 기준
  - [ ] "`## 경로 기준`" 메시지를 출력한다.

  - [ ] 입력 받을 `기준 목록`을 출력한다.
    ```
    ex:
    1. 최단 거리
    2. 최소 시간
    B. 돌아가기
    ```
    
  - [ ] 기능 목록 입력 안내 메시지를 출력한다.

    -> "`## 원하는 기능을 선택하세요.`"


- 3. 경로 조회 시작
  - [ ] 출발력 입력 안내 메시지를 출력한다.
  
     -> "`## 출발역을 입력하세요.`"

  - [ ] 도착역 입력 안내 메시지를 출력한다.
  
     -> "`## 도착역을 입력하세요.`"


- 4. 경로 조회 결과
  - 경로 조회 시 각 `형식`에 따라 정보들을 출력한다.

  - [ ] `"## 조회 결과"` 메시지를 출력한다.

  - [ ] '총 거리' 및 '총 소요 시간'을 출력한다.
    ```
    ex:
    [INFO] ---
    [INFO] 총 거리: 4km
    [INFO] 총 소요 시간: 11분
    [INFO] ---
    ```

  - [ ] '경로 상 역 이름'을 나열하여 출력한다.
    ```
    ex:
    [INFO] 교대역
    [INFO] 강남역
    [INFO] 양재역
    ```


### 경로 조회 규칙
- [ ] 출발역과 도착역은 달라야 한다.
- [ ] 경로 조회 시 총 거리, 총 소요 시간도 함께 출력한다.
- [ ] 경로 조회 기준은 최단 거리 최소 시간이 있다.


### 엣지케이스
- [ ] 경로 조회 시 출발역과 도착역이 같으면 에러를 출력한다.
- [ ] 경로 조회 시 출발역과 도착역이 연결되어 있지 않으면 에러를 출력한다.
- [ ] 그 외 정상적으로 프로그램이 수행되지 않은 경우 에러를 출력한다.
